House rules — how the fleet is governed

Agents do the work. They never get the judgment.

Anyone can prompt an AI to write code. The hard part is trusting what comes back. Red Owl's answer is a written rulebook the fleet actually runs on:

RULE 01 — HUMAN HARD LINES

Money, access, personal data

No agent moves money, touches credentials or deletes personal data. Ever. Those three calls are made by a person, on the record.

RULE 02 — ADVERSARIAL GATES

Refute before merge

Before work ships, an independent agent tries to tear it apart — up to three passes. Nothing merges without a green verdict it failed to refute.

RULE 03 — BLIND CONTROLS

Honeypots in every audit

Audits include planted cases the auditor can't recognize. These controls have caught a model fabricating results — and blocked it. That's why the numbers can be trusted.

RULE 04 — DECISIONS ON RECORD

ADRs, not vibes

Every architectural decision is written down and versioned. Agents consult the record before acting; nothing gets silently re-decided.
